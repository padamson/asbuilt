version asbuilt_site.version

crates/site/src/version.rs

The build's version identity and the one place the site's path prefix is spelled. build.rs injects SITE_VERSION; the deploy serves every snapshot under /asbuilt/<dev|vX.Y.Z>/ (project Pages), and only the version switcher needs to know that: every other asset path is relative.
